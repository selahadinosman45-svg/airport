# Airport Briefings

Static site, no build step. Deploy on GitHub Pages from the repository root.

## Updated briefing features
- Individual Domestic Briefing airport entries, searchable by airport name, IATA and ICAO.
- Per-airport SID / departure and depressurization escape-route pop-ups.
- OMDB (Dubai) and NSI (Yaounde) briefing records from the supplied PDFs and crew notes.
- Airport source-page details retained under each applicable Domestic Briefing airport.
- METAR/TAF fetch from Aviation Weather Center where available, with an AI-assisted plain-language explanation handoff to ChatGPT.
- NOTAM lookup links and a paste-to-explain workflow for AI-assisted NOTAM interpretation.
- Existing route progress, weather, pinning, navigation and dark/light theme features retained.

## Important operational limitations
- Domestic Airport Information source document is dated 09 September 2024. It is historical reference material, not a current AIP.
- NOTAMs are not automatically retrieved inside this static site because the official services have differing access and authentication requirements. Use the linked official service, paste the NOTAM into the briefing and open the AI explanation.
- AI explanations are handed off to ChatGPT; they are not generated by a private API embedded in this static website.
- Weather fetches are subject to Aviation Weather Center availability and airport coverage. Existing Open-Meteo weather cards are model data, not METAR/TAF.
- Always verify current charts, NOTAMs, clearances, performance requirements and company-approved procedures before operational use.
